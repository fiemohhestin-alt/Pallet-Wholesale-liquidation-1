# Pallet Wholesale Liquidation

A responsive landing-page prototype for a wholesale liquidation business.

## Preview
Open `index.html` locally, or deploy the repository to Render.

## Files
- `index.html` — main website
- `styles.css` — responsive styling
- `script.js` — small interactive behavior

## Before going live
Replace the placeholder email/phone details and connect any real inventory, checkout, authentication, database, or admin features you want to add.
